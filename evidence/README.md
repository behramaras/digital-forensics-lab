
# Sample Evidence Files

This directory contains fictional files created specifically for
a controlled digital forensics learning exercise.

## Files

- `meeting_notes.txt`: Synthetic meeting notes.
- `expenses.csv`: Synthetic expense records.
- `project_summary.txt`: Synthetic project summary.

## Handling Notes

- These files do not contain real client or personal data.
- The files are used to practise SHA-256 hashing and integrity checks.
- File integrity results apply only to the comparison performed
  against the recorded hash manifest.
- This directory is not a real forensic evidence collection.
